## What was done

1. **Pruned the three merged remote branches** — `kb/1.4.0-merch-launch-codification`, `playground-main`,
   `wt/t_046dc919`. Remote now holds only `main`. Safety was proved with a **two-dot** tree diff, not
   `git branch --merged`, because every merge here is a squash merge and `--merged` reports a fully merged
   branch as "diverged / 15 ahead".
2. **`baseline.env` + `check-baseline.sh`** — the count now lives in one sourced file, and a new gate
   fails when any document disagrees with it, when the on-disk test-file count moves, or when
   `overview.md`'s list stops matching. **Observed red first: 6 FAILs, then green.**
3. **All six carriers reconciled** to the measured count; `AGENTS.md` §5 rewritten to name every carrier
   and the guard, so the next change cannot drift silently.
4. **Version scheme declared** in `AGENTS.md` §2 and `stack/overview.md#versions`; the roadmap field in
   `lib/brand-config.ts` renamed `version` → `roadmapId` with a header stating it is not a release record.
   **T24 → MITIGATED.**
5. **`docs/releases/RELEASES.md`** — the release ledger the repo never had, recording the four untagged
   releases and the intended `v0.2.0` tag target.
6. **KB bumped to 1.5.0** (two new traps), with a changelog entry.
